This is a simple Chrome extension to convert a Spotify link to Youtube Music

## Features

- convert any spotify link pasted
- convert an open Spotify tab
- open the YT link in a new tab

## Installation

 - open `chrome://extensions` in the address bar or use menu->extensions->manage extensions
 - activate the developper mode
 - Load extension by pointing to the directory
 - pin the extension for easy access

## Usage

open a spotify link in a tab and the extension will detect it and convert it in a YT music link
or paste a spotify link directly in the extension
if the track is found, you can open it directly or copy the link
